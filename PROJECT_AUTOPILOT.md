# Project Autopilot

This is the live operational cockpit for autonomous execution.

## Mission
Advance the approved product outcome with minimal HOVA involvement.

## Loop
Restore state; select the highest-value executable task already in scope; implement on a feature branch; validate; repair failures and stale metadata; open/update the PR; resolve findings; mark ready and merge when `AGENTS.md` conditions are met; update this file and continue.

## Current state
- Phase: derive from repository evidence
- Active objective: derive from roadmap, issues and merged state
- Last verified head: update every run
- Open PRs and CI: inspect before work

## Priority
1. red CI/security/privacy;
2. data-loss or production-safety risk;
3. active-outcome blocker;
4. missing tests/evidence;
5. highest-leverage scoped improvement;
6. docs/cleanup.

## Rules
Record material technical decisions with evidence and rollback. Aggregate blockers into one decision packet. Continue unrelated safe work first. No secrets or real protected data. Production, public launch and DNS remain outside autonomous scope.

## Completion report
Current head, PRs, validation evidence, updated queue, blockers and next task selected or started.
